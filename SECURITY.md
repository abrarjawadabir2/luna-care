# Security Policy

## Supported Versions

We take the security and privacy of LunaCare and its users seriously. The following versions are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability or privacy flaw in LunaCare, please report it responsibly:

1. **Do Not File Public Issues:** Please do not open a public GitHub issue or disclose the vulnerability publicly until it has been investigated and remediated.
2. **Private Reporting:** Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/abrarjawadabir2/luna-care/security/advisories/new) or by contacting the project maintainer directly.
3. **Information to Include:**
   - A description of the issue and potential impact.
   - Minimal steps or proof-of-concept demonstrating the behavior.
   - Affected platform, component, or version.

We will acknowledge receipt within 48 hours and work with you to coordinate a timely, safe fix.
